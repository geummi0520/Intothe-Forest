## 🎮 프로젝트 소개

이야기숲으로!는 한국 설화를 바탕으로 한 2D 픽셀 웹게임입니다.

플레이어는 삶의 여정을 따라 여러 공간을 이동하며, 각 맵에서 NPC와 대화하고, 설화를 읽고, 그 안에 담긴 의미를 아이템으로 수집하며 다음 단계로 나아갑니다.

게임에서 플레이어는 시간의 흐름에 따라 삶의 단계마다 스며든 설화를 만나 성장하며 탄생과 성장, 사랑과 상실, 그리고 마무리에 이르는
여정을 걸어갑니다. 각 설화는 당신의 선택과 감정에 따라 다른 의미로 빛나며, 그 모든 경험이 모여 하나의 개인적
신화, 당신만의 ‘삶’이 완성됩니다.

이곳에서 설화는 옛이야기가 아니라, **지금 이 순간을 살아가는 우리 모두의 이야기**가 됩니다.

<br/>



## 🧭 게임 흐름


게임은 총 4개의 공간으로 구성되어 있으며, 각 공간은 삶의 한 단계를 상징합니다.



| Stage   | Map | Theme                   |

| ------- | --- | ----------------------- |

| Stage 1 | 고향  | 탄생과 관련된 설화              |

| Stage 2 | 광장  | 가족, 사랑 등 삶 속 고민과 관련된 설화 |

| Stage 3 | 숲   | 삶의 마무리와 관련된 설화          |

| Ending  | 공항  | 삶의 여정을 마무리하고 떠나는 공간     |



플레이어는 각 맵에서 설화를 가진 NPC를 만나고,

설화 속 의미가 담긴 아이템을 하나 선택해 수집한 뒤 다음 공간으로 이동합니다.



<br/>



## ✨ 주요 기능



### 1. Phaser 기반 픽셀 웹게임 구현



Phaser를 활용해 브라우저에서 실행되는 2D 픽셀 게임을 구현했습니다.

Canvas 기반 렌더링과 픽셀 아트 설정을 적용해 레트로한 게임 분위기를 살렸습니다.



### 2. 씬 단위 게임 구조 설계



게임의 흐름을 여러 Scene으로 분리해 관리했습니다.



* `PreloadScene` : 게임에 필요한 이미지, 타일맵, 캐릭터, UI 에셋 로드

* `StartScene` : 시작 화면 및 More 팝업

* `IntroScene` : 게임 도입부 연출

* `FirstMap`, `SecondMap`, `ThirdMap`, `FourthMap` : 각 스테이지 맵

* `TalePopupScene` : 설화 상세 보기 및 아이템 수집

* `EndScene` : 엔딩 및 다시 시작



### 3. NPC 대화 및 설화 인터랙션

플레이어가 NPC와 상호작용하면 대화 UI가 표시되고,

대화가 끝난 뒤 해당 NPC가 가진 설화를 읽을 수 있습니다.



설화 팝업에서는 이야기 본문과 함께 설화의 의미를 담은 아이템이 제공되며,

플레이어는 그중 하나를 선택해 수집할 수 있습니다.



### 4. 아이템 수집 및 진행 조건 관리


각 맵에서 설화를 읽고 아이템을 수집해야 다음 맵으로 이동할 수 있도록 구성했습니다.

수집한 아이템 정보는 전역 데이터 매니저를 통해 관리되며,

씬이 전환되어도 플레이어의 진행 상태가 유지됩니다.



### 5. 타일맵 기반 맵 구성

Tiled Map Editor에서 제작한 맵 데이터를 활용해 충돌 영역, NPC 위치, 이동 가능 영역을 관리했습니다.

각 스테이지는 배경 이미지, 충돌 레이어, 오브젝트 레이어를 조합해 구성했습니다.

## 🧩 구현 포인트



### Scene 기반 게임 플로우 설계



시작 화면, 인트로, 맵, 설화 팝업, 엔딩을 각각 독립적인 Scene으로 분리했습니다.

이를 통해 게임 흐름을 단계별로 제어하고, 특정 UI나 맵 로직이 다른 장면과 과도하게 섞이지 않도록 구성했습니다.



### Pause / Resume을 활용한 설화 팝업 처리



NPC와 상호작용하면 현재 맵 Scene을 일시정지하고 설화 팝업 Scene을 실행합니다.

플레이어가 아이템을 선택하면 팝업 Scene을 종료한 뒤 기존 맵 Scene으로 돌아가며,

선택한 아이템 정보를 전달해 다음 진행 조건을 갱신합니다.



### 대화 UI와 선택지 인터랙션 구현



대화창에는 타이핑 애니메이션을 적용해 이야기 전달감을 높였습니다.

대화 중에는 캐릭터 이동을 막아 입력 충돌을 줄였고,

선택지 UI를 통해 플레이어가 설화를 읽을지 직접 결정할 수 있도록 했습니다.



### 전역 데이터 매니저를 통한 상태 관리



플레이어 위치, 방향, 맵별 방문 여부, 인벤토리 정보를 전역 데이터 매니저에서 관리했습니다.

이를 통해 씬 전환 후에도 플레이어의 진행 상황을 유지할 수 있도록 했습니다.
